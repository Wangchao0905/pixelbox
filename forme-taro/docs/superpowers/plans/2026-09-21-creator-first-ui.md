# Creator-First UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refocus FORMÉ's WeChat mini-program UI on entering a creative workflow quickly and completing a generation confidently.

**Architecture:** Preserve existing Taro pages, generation APIs, data, and dark/lime brand tokens. Add two small UI-only modules for navigation and generation-control state, then refactor existing page composition and SCSS around those modules. No backend endpoints, page routes, or billing rules change.

**Tech Stack:** Taro 4, React 18, TypeScript, Sass, Node test scripts.

**Spec:** `docs/superpowers/plans/2026-09-21-creator-first-ui.md`

## Global Constraints

- Keep `BATCH_SIZE = 1`; generation buttons must visibly say `生成 1 张`.
- Keep reference image upload available from the phone album with a five-image maximum.
- Do not add routes or dependencies.
- Keep the existing AIGC disclosure overlays and export behavior.
- Only expose destinations that have working screens in primary navigation.
